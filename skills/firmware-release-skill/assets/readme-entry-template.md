# README 变更日志条目模板

发布仓库 `README.md` 的 `## 变更日志` 条目格式（新条目在最上方）：

```markdown
### YYYY-MM-DD

- **feat**: 发布 {Product} V{版本} 组{组号} 固件（可选改动说明）（`{bcmu|bmu|hmi}`）
```

## 示例

```markdown
### 2026-08-18

- **feat**: 发布 BCMU V5.1.7.12 组20 固件（扩展故障补全 8 位：动环通讯预警/告警/保护、外部禁充/禁放反馈）（`bcmu`）
- **feat**: 发布 BCMU V3.3.0.7 组5 固件（`bcmu`）
```

## 规则

- 同一日期的多次发布合并进同一个 `### 日期` 块，新条目在该块内排最上方
- 条目以 `- **feat**:` 开头，末尾标注发布子目录（`bcmu` / `bmu` / `hmi`）
- 补充说明（可选）放在固件名之后、子目录标注之前，用全角括号包裹
